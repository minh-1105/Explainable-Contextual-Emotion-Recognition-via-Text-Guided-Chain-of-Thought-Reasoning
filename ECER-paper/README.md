# ECER-paper: Present 3 paper (IEEEtran, conference mode)

Paper for "Explainable Contextual Emotion Recognition via Text-Guided Chain-of-Thought Reasoning" (Group 10). The text describes the role-separated pipeline of `notebooks/04_Qwen3_Multimodal.ipynb` and reports its full run `20261104-071259-h100` on the validation eval half and on all 7,280 test people, with explanations for every eval and test person.
